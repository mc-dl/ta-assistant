# ─── 课程事务事实表 · 样例 ──────────────────────────────────────────
#
# 【怎么用】
#   把本文件复制成  ~/ykt_questions/课程事务.txt  (即 WINDOWS_ROOT 下,和
#   常问问题.txt 放在一起), 然后把下面的示例内容改成**真的**。
#   系统每次答疑都会读它,改完**立即生效**,不用重建索引。
#
# 【为什么要有这张表】
#   事务信息(截止时间、提交方式、评分)每学期都会变,而 常问问题.txt 里的
#   条目是"写下来就不再变"的 —— 实测事务类提问 90% 都命中 FAQ,也就是说
#   改一次规则,那条旧答案照样会被命中、而且说得很自信。
#   这张表带「生效/失效」日期,过期就自动不再被使用;它**优先于** FAQ 和
#   课程资料 —— 所以改规则只改这一处。
#
# 【格式】
#   块之间空行分隔;`#` 开头整行是注释;半角 `:` 全角 `：` 都认。
#   「事实」必填,其余可省。「生效」省 = 一直算数,「失效」省 = 一直有效。
#   日期写法:2026-09-01 / 2026/9/1 / 2026.9.1 / 2026年9月1日 都行。
#   ⚠️ 日期写错、缺「事实」、失效早于生效 —— 那一块会被**跳过并在 stderr 告警**,
#      宁可这条不生效,也不能拿一条算不清还算不算数的规则去回答事务问题。
#
# 【注意】
#   这张表要**保持小**(几十条以内):事务类提问每次都会把它整块塞给大模型。
#   下面全是**示例**(标了【示例·请替换】),照抄进真文件之前请改成真的 ——
#   事务信息说错一个数字,比"不知道"严重得多。
